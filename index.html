DietPi · OpenCode · code-server

DietPi x86_64 – OpenCode + code-server + Git + GitHub CLI als Docker-Container. Das Image wird automatisch per GitHub Actions gebaut und auf GHCR gepusht.

ghcr.io/jbkunama1/hAI.OpenCodeContainer:latest

⚙️ Quickstart

Per Portainer Stack pullen – nicht lokal bauen.

1-StackPortainer
8080Port
autoUpdates

📁 Deployment per Portainer Stack

  1. Stacks → Add stack
  2. Name: z. B. opencode
  3. Build method: Web editor mit Inhalt aus compose.yml:
services:
  dev:
    image: ghcr.io/jbkunama1/hAI.OpenCodeContainer:latest
    environment:
      PASSWORD: "${CODE_PASSWORD}"
      OPENAI_API_KEY: "${OPENAI_API_KEY:-}"
      ANTHROPIC_API_KEY: "${ANTHROPIC_API_KEY:-}"
      OPENROUTER_API_KEY: "${OPENROUTER_API_KEY:-}"
      GH_TOKEN: "${GH_TOKEN:-}"
    volumes:
      - "./projects:/home/coder/project"
      - "coder-home:/home/coder"
    ports:
      - "127.0.0.1:8080:8080"
    restart: "unless-stopped"
volumes:
  coder-home: {}

Registry-Zugriff: public Image → latest ohne Credentials. Privat → GHCR-Registry in Portainer mit PAT (Scope read:packages).

🔄 Auto-Updates

🔄 Poll for Updates

Webhook aus Portainer unter Stack settings → Poll for updates kopieren und im Repo unter Settings → Webhooks anlegen (Event Package published).

🔭 Watchtower

Kein GitHub-Trigger nötig:

docker run -d --name watchtower \
  -v /var/run/docker.sock:/var/run/docker.sock \
  containrrr/watchtower:latest \
  --interval 3600 --cleanup
